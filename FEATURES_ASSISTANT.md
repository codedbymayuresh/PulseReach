# PulseReach Assistant

Added a polished rule-based PulseReach Assistant widget. It uses predefined intent matching and responses; no AI API is required. It is intended as a navigation/help assistant for the prototype.

## Included
- Floating assistant launcher
- Chat panel with typing state
- Quick actions
- Drive registration help
- Donor account/login help
- Donation history help
- E-certificate help
- Reminder/consent guidance
- Medical eligibility boundary message
- Responsive mobile layout
